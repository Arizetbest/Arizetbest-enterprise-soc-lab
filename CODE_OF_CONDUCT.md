# Code of Conduct

## Our standards

This project welcomes respectful, constructive participation. Contributors should demonstrate empathy, technical accuracy, responsible disclosure, and respect for privacy and authorization boundaries.

Unacceptable behavior includes harassment, discriminatory language, publishing private information, unsafe security instructions, or using project spaces to facilitate unauthorized activity.

## Enforcement

Report conduct concerns privately to the repository owner through the contact method on the GitHub profile. The maintainer may edit or remove content and temporarily or permanently restrict participation when necessary to protect the community and project.
